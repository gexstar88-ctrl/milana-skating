# Милана — спортивный дневник

Публичная статическая версия существующего дневника. Публикация GitHub Pages: main, /(root). Все пути относительные; Git LFS и серверная часть не требуются.

Обновление: Codex проверяет первоисточник в локальном проекте, запускает scripts/build_public_site.py, браузерные проверки и отправляет только содержимое public-site/ в этот репозиторий. Исходные личные архивы и ключи не публикуются.

Индексация страницы отключена через meta robots noindex. robots.txt разрешает чтение страницы и картинки для карточек ссылок в мессенджерах. Запрет индексации не ограничивает доступ по прямой ссылке и не является средством конфиденциальности.
